**Potentially misleading claims and checks that could disprove them**

- **Init — hero/01:** Verify click-to-read behavior, restricted read-only AI tools, provider data flow, files-only mode and account-free configuration generation against `cli/init.mdx` and `StartStep.tsx`. Check that analysis does not deploy or take over existing resources. AI-provider charges may apply; optional local build tests can execute code and download dependencies before deployment.
- **Coverage and packaging — 01/02:** Check supported workloads, extension mechanisms, local-development behavior and artifact reuse. A missing reusable artifact must permit rebuilding. Verify the remote runner is EC2 in the customer account.
- **Deployment — 03:** Verify configured Git rules, independent preview resources, closure cleanup and retained-artifact rollback. Previews must not imply copied production data. Gradual container rollout requires an eligible ALB-backed service.
- **Monitoring — 04/06:** Verify actual launch coverage. Issues are off by default and require redeployment after enablement; raw-log grouping has limits. Probes and synthetic checks require configuration. Container tracing needs instrumentation; runtime and deployment-mode exclusions remain. Correlation must not be presented as causation.
- **Security — 01/05:** Verify policies actually enforce the depicted protections. Standard database defaults are not universally private, and connection policies are not necessarily minimum privilege. Missing scan coverage must remain visible. Leaked credentials require revocation or rotation; a secret reference alone does not remediate exposure.
- **Costs — 07:** Reconcile attributed, shared and unattributed costs with delayed AWS reports. Test threshold and forecast alerts without implying a spending cap or guaranteed advance warning. Verify launch pricing separately; no free-team or fee-free promise is made.
- **Visuals and endorsements:** Proposed routes, controls, validation states and screen compositions require product review. Illustrations are not execution evidence. Verify links, footer claims and continued testimonial permission before publication; supplied quotations remain verbatim and do not endorse the roadmap.
