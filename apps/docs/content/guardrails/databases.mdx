# Database guardrails

These guardrails decide which SQL engines and instance sizes your team can use, and which Stacktape resource types are
off-limits. They appear under **Database restrictions** on **Security → Guardrails**.
[Guardrails overview](/guardrails/overview) explains who they bind and how to set them up.

Private network access and deletion protection for databases are on
[Security and data protection guardrails](/guardrails/security-and-data-protection).

## Allowed database engines

Every [relational database](/resources/databases/relational-database) must use one of the engines you list. Other
database types, such as DynamoDB, OpenSearch, Redis or Aurora DSQL, aren't checked; block them with
[Blocked resource types](#blocked-resource-types).

The engine identifiers are the values of `engine.type`:

| Family | Identifiers |
|---|---|
| PostgreSQL | `postgres`, `aurora-postgresql`, `aurora-postgresql-serverless-v2` |
| MySQL and MariaDB | `mysql`, `mariadb`, `aurora-mysql`, `aurora-mysql-serverless-v2` |
| Oracle | `oracle-ee`, `oracle-se2` |
| SQL Server | `sqlserver-ee`, `sqlserver-ex`, `sqlserver-se`, `sqlserver-web` |

To standardize on PostgreSQL, list all three PostgreSQL identifiers, so teams can still choose between a fixed instance,
Aurora and Aurora Serverless.

## Allowed database instance sizes

Every provisioned database instance must use one of the sizes you list, such as `db.t4g.medium`, `db.r6g.large`. The
check covers the primary instance and read replicas of standard RDS engines and the instances of Aurora clusters. Aurora
Serverless v2 has no instance size and isn't checked.

The list is an allowlist: a size nobody reviewed, including a new one AWS adds later, stays blocked until you add it.
Rules created before allowlists blocked listed sizes instead; they still work until you edit them.

## Blocked resource types

No config may declare a resource of the types you list, for example `open-search-domain` or `redis`. Any Stacktape
resource type can be listed, not only databases:

```text
Blocked by the organization guardrail "Blocked resource types". Resource `search` uses blocked type
`open-search-domain`. Blocked resource types: `open-search-domain`.
```

Use it for services your organization hasn't approved, or that cost more than a team should start on its own. A rule
that lists the old `redis-cluster` type also blocks `redis`.
